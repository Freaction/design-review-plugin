Этот плагин нужен для дизайн-ревью со стороны команды дизайн-системы. У нас есть эталонный юай кит, в котором находятся компоненты, а также 4 библиотеки переменных, которые подключаются по мере надобности. Их 4 из-за ограничений фигмы, сейчас у нас 140 модов, а это 140 брендов. Плагин должен быть построен на модульной архитектуре и esbuild, который будет собирать как фронт-енд, так и бек-енд. Необходимо, чтобы каждый модуль был в своем файле, и чтобы компоненты были построены также модульно, т.е. для каждого компонента свой css-файл, а не огромное большое полотно. Работай только в папке main

Суть плагина вот в чем:
1. Нужно разработать автоматизацию для выявления в фичевом макете:

2. оверрайдов на компонентах ДС (сверка компонентов в макете с эталонным китом)

3. старых версий компонентов ДС (сверка компонентов в макете с эталонным китом)

4. раздетаченных компонентов

5. некорректного использования переменных для текстов (для текстов должны использоваться только переменные с неймингом text.., description…, label…
