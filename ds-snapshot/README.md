# Эталон ДС для Design Review

Загружается плагином у всех пользователей без доступа к UI-Kit.

## Файлы

- `meta.json` — лёгкий манифест версии (плагин проверяет при старте)
- `snapshot.json` — полный эталон компонентов

## Как обновить

1. Открой UI-Kit в Figma с правами редактора.
2. В плагине вкладка «Скан эталона ДС» → «Отсканировать UI-Kit».
3. Нажми «Экспорт для GitHub» — скачаются `meta.json` и `snapshot.json`.
4. Замени файлы в этой папке и запушь в `main`.
5. У пользователей кнопка «Обновить эталон» подтянет новую версию.

## Версия

Поле `version` в `meta.json` должно меняться при каждом обновлении
(например `2026.07.30` или `1.2.0`). Плагин сравнивает именно его.
